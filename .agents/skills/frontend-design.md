# Skill: Frontend Design & Vanilla CSS Architecture
Garante código front-end limpo, sem frameworks e semanticamente correto.

## Regras de Execução
- **Sem Estilos Inline:** É terminantemente proibido injetar o atributo `style="..."` diretamente nas tags HTML. Todo estilo deve ir para os arquivos `.css`.
- **CSS Moderno:** Use exclusivamente `display: flex` e `display: grid` para estruturas de layout. Não use tabelas para layout ou posicionamentos flutuantes antigos.
- **Estados Interativos:** Toda classe de botão, link ou item clicável deve obrigatoriamente ter regras explícitas para as pseudo-classes `:hover`, `:focus-visible` e `:active`.
- **Acessibilidade Basica:** Garanta contraste de cor adequado e o uso correto de tags semânticas (`<header>`, `<main>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
